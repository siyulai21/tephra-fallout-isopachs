## A case has one home

`eruptions/<slug>/README.md` explains the question and links to the evidence. `results/` contains the current reviewed maps, numerical report and candidate tables. Source files and accepted inputs remain in the central [data collection](../data/README.md), with no duplicate working copies.

Earlier analyses live in [the archive](../archive/reports/README.md), linked from each case. Their domains or input selections can differ; they must not be combined with current results as though they estimated the same quantity.
