# Sampling evidence for Pinatubo Layer C

The 155 directional and spherical attempt records refer to 132 distinct posterior files. Each row gives the design, retry number, sampler outcome, file path and SHA-256. The saved draws include attempts that retained numerical warnings. [Draw files and hashes](attempts.csv) · [Sampling settings and diagnostics](diagnostics.json)

The hosted workers verified input, design and draw identities before resuming completed attempts. The released protocols supplied the seeds, retry limits and eight spherical prior settings. The regional pair used a separate hosted worker.
