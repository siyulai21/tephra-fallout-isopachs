# Spherical sampling evidence for Pinatubo Layer C

The 29 posterior files cover the eight fixed priors and four buffered geographic holdouts. Each attempt records its settings, sampler diagnostics, seed and draw checksum. The final three-fan baseline reached maximum R̂ 1.528. The five-fan sensitivity reached 1.040 after three attempts.
