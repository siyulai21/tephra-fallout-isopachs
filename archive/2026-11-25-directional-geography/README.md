# Directional maps before the multiscale fit

These are the finite-spread, uncertain-azimuth maps on the same accepted eruption inputs used in the paired geographic study. Each folder retains its original grid, plot, integrated area table, numerical receipt and report text. The repository revision preserves the complete case homes with their original relative links.
