# Initial Bayesian nested-isopach estimates

This development version placed its distal priors on thinning slopes. For Aso-4 and Ilopango, those slopes admitted thick deposits far beyond the measured range. Each directory retains the initial maps, area–thickness curve, full and geographically withheld draws, volume budgets and numerical attempts. The matched revision uses the same observations and geographic folds.
