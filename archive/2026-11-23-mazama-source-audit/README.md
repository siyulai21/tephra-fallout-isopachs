# Mazama before the source revision

The [complete previous case and original CSV](previous-release.tar.gz.parts.json) preserve the published45-observation fit from [GitHub revision0a53d02](https://github.com/siyulai21/tephra-fallout-isopachs/tree/0a53d02/eruptions/mazama). [Per-file fingerprints](files.json) identify every preserved byte. Earlier original-source and interrupted-run histories are linked from the [audit](../../data/audits/Mazama/README.md).

The current source revision changes observations, coordinates, bounds and the common regional hull. Differences in volume cannot be attributed to a single source correction or treated as performance on an unchanged dataset.

[previous-release.tar.gz reconstruction manifest](previous-release.tar.gz.parts.json) lists ordered byte parts, sizes and SHA-256 hashes. Concatenation reproduces the original archive exactly; all archived scientific files and their recorded hashes are unchanged.

The [previous cross-eruption tables, reports and figures](previous-catalogue.tar.gz) retain the corresponding catalogue views from the same revision. The [catalogue file inventory](previous-catalogue.json) identifies each original by path and SHA-256.

The Aso-4 audit preserved 34 Mazama files as an external comparison on 8 November, before later changes to the maps and source data. The archive contains those original bytes under their original paths. The Aso-4 check validates each against the original study inventory and checks each subsequent Mazama replacement against the current publication.
