# How much did the two land-map reviews change the estimates?

All five families were fitted again after two readers checked four Koyaguchi sublayer labels and 32 Paladio-Melosantos Figure 7 entries. Fourteen Layer C observations entered the shared input and two previously fitted Figure 7 thicknesses changed. Every earlier site retained its position. The regional hull remained the same size. Each pair of volumes below integrates the same family’s median field over the same domain.

| Family | Before (km³) | After (km³) | Change |
|---|---:|---:|---:|
| Regional GP | 3.50 | 3.45 | -1.3% |
| Regional cubic spline | 13.17 | 14.82 | +12.6% |
| Directional ensemble | 6.57 | 6.42 | -2.4% |
| Spherical mixture | 13.70 | 13.92 | +1.6% |
| Nested corridors | 7.58 | 8.36 | +10.3% |

The lower and upper conditional limits, both fit hashes and the three numerical and validation flags for each release are available alongside these central estimates. The differences include Monte Carlo variation in families that sample a posterior.
