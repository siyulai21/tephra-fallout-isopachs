# Earlier Pinatubo and Ilopango inputs

These editions supply the matched observations, fits and holdouts for the published method comparisons. The eruption pages show the latest audited inputs. All volumes below are integrals of median-thickness maps.

## Pinatubo

The **208-site Layer C** edition pairs all five methods on the same observations. Its nested estimate was 6.70 km³. The 235-locality audit preserved reviewed land readings, recovered additional marine evidence and fitted the reported thickness ranges.
