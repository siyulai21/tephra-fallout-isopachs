# Historical four-eruption regional summary

[Current report catalogue](../../../reports/README.md) · [Current global comparison](../global-fallout/README.md)

These unchanged [CSV](summary.csv) and [JSON](summary.json) summaries belong to the earlier Mazama, Tambora, Aso-4 and B-Tm **Gaussian-process** reports. They use finite calculation rectangles and are preserved for provenance. They are not original cubic-spline results or current global headlines.

The corresponding maps and numerical records are in each eruption's `regional/` folder.
