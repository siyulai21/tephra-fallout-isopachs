Current headlines integrate the complete physical WGS84 Earth, independently of arbitrary calculation rectangles. The estimates remain conditional on global extrapolation assumptions; no global probability intervals are claimed. Earlier regional summaries are preserved as `REGIONAL_REPORT.md`. The four original reports were relocated without changing their numerical results. The former atlas/browser interfaces have been removed; historical implementation remains accessible through Git history.
