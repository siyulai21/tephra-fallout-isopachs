# Before uncertain fan direction became primary

This archive preserves the case pages, numerical summaries, validation tables and presentation figures replaced when the uncertain-fan-direction map became the principal directional estimate. The preceding release already contained all six uncertain-direction reconstructions as sensitivities. Its posterior fields, whole-Earth volumes, intervals and matched control values are also the source of the current principal results.
