# Site evidence worksheet

Copy one record per physical site and eruption horizon into the case audit, or use equivalent columns in the existing ledger. An agent can complete it from the supplied sources and the literature. A contributor can supply a site name or citation and leave the remaining fields open. [Review protocol](../docs/methods/sites-without-measured-thickness.md)

| Record | Details to enter |
|---|---|
| Identity and target | Stable evidence ID, source row and codes, site and core/section aliases, evidence for eruption correlation, local age evidence or assigned marker age, included phases and deposit convention. |
| Deposit classification | Literal source class and legend, who assigned it, and field log or compilation inspected. Record evidence for emplacement, original thickness preservation, and any conflict with the fitted reading. |
| Position and geometry | Coordinates, datum, precision and source. Distance and bearing from vent, affected contour levels or sectors, nearby independent measurements and their IDs. Record the evidence for low influence if that is the basis for omission. |
| Sources inspected | Primary paper, supplement or log, version/hash if available, page/figure/table and depth. For an unresolved lead, record the additional sources or searches tried, the access limitation and what would resolve it. |
| Actual observation | What the investigators found or explicitly looked for, host material, recovery, disturbance, samples and controls. Keep original values, units, detection method, grain sizes and window. |
| Calculation | Target of the bound, formula, measured and digitized inputs, calibration, density and retention assumptions as applicable. Link extracted data or arithmetic that reproduces the limit. Record both endpoints independently, outward rounding and uncertainty. |
| Decision | Principal point, two-sided interval or one-sided limit (reported or interpreted), duplicate with accepted ID, sensitivity only, occurrence or component check, unresolved, or low-influence omission. Record why, any remaining missing quantity, and the accepted CSV row/ID if fitted. Leave unknown endpoints empty. |
| Dependence | Other names for the same core, overlapping samples, shared calibration, competing sources and sites to omit or vary together. |
| Result and history | Link principal, omission, weaker-response or geographic holdout results as applicable. Record changes in local contour reach/area and volume, footprint used, numerical warnings and the preceding decision for a recalculation. |

For a calculated limit, a reader should be able to start with the cited observation, recover the unrounded endpoint in cm and locate the single likelihood row. For an omitted site, a reader should be able to identify the physical quantity still missing or the documented evidence for low geometric influence.
